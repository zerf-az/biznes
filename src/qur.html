Как отдать клиенту

1. Файлом в WhatsApp. Скрепка → «Документ» → выбрать файл. Он откроется у человека прямо в телефоне и будет работать даже без интернета. Самый чистый способ: адрес не подделать.

2. Ссылкой. Быстро, но в адресе видно #ad=Leyla. Для дешёвого заказа нормально.

3. Своей ссылкой. На github.com в репозитории biznes: Add file → Upload files → закинь файл в папку z с новым именем. Получится адрес вида …/biznes/z/leyla.html — красиво и без параметров.
